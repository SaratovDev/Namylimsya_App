# Намылимся

Площадка для организации живых встреч и офлайн-событий. MVP.

## Стек
- **Frontend:** Next.js (React + TypeScript), Tailwind CSS, next-themes
- **Backend:** Go (chi + gorilla/websocket) — REST + WebSocket
- **БД:** PostgreSQL 16 + PostGIS 3.4
- **Кэш/очереди:** Redis 7
- **Email (dev):** Mailpit
- **Карты:** Яндекс.Карты
- **Инфраструктура:** Docker Compose

## Быстрый старт

### 1. Требования
- Windows 10/11, Docker Desktop (WSL 2)
- Node.js 20+, pnpm
- Go 1.22+
- Git
